什么是git？
    git是一个开源的分布式版本控制系统，可以有效的处理项目的版本（就是个工具，上传下载代码用的，控制代码
    的版本）
用处？
    在多人协作的时候更方便，实现代码同步
下载并安装：
    注意安装路径不要有中文
    安装完毕之后，用鼠标在任何文件夹下空白处右键，出现git bash here 表示安装成功

平台---存储代码的一个仓库 gitee（码云） github 云效
用gitee演示
1.在gitee上注册一个账号，绑定邮箱（登录成功之后右上角账户设置--邮箱管理），否则后期无法加入平台的项目组，
如果加不进去你就没法有权限修改平台
2.登录上码云，点击头像左侧＋，创建仓库（仓库相当于远程电脑上的一个文件夹，里边存储的是代码，输入仓库名称，
选择私有，点击创建按钮就可以创建一个空白仓库，创建完成之后选择初始化readme文件）

首次使用需要配置自己的用户名和邮箱 在文件夹空白处右键---git bash here 然后分别输入命令
    git config --global user.name "默认用户名"
    git config --global user.email "默认邮箱"
注意 此处使用--global 那么该命令只需要执行一次 就可以永久生效（全局修改）
用户名和密码首次输入需要正确

假设账户密码需要更好或输入错误
    打开控制面板--右上角类别选择小图标--凭据管理器--Windows凭据--普通凭据--找到git账号和密码删掉

每个项目可以设置不同的提交用户名和邮箱，不用反复修改全局配置
    git config --local user.name "这个项目使用的用户名"
    git config --local user.email "这个账号绑定的邮箱"

可以一个项目用 GitHub，另一个项目用 Gitee，完全可以同时使用。
这个项目的提交署名：
    git config --local user.name "你的用户名"
    git config --local user.email "你在Gitee绑定的邮箱"

查看当前项目用（配置）的是哪个邮箱用户名：
    git config user.name
    git config user.email



这个项目上传到哪个仓库：
如果你是用 git clone 从 Gitee 下载的项目，仓库地址通常已经设置好了，可以查看：
git remote -v
如果已有的 origin 地址需要换成 Gitee：
git remote set-url origin https://gitee.com/你的用户名/仓库名.git

如果还没有 origin，则用：
   git remote add origin https://gitee.com/你的用户名/仓库名.git
用户名和邮箱决定提交署名，远程仓库地址决定上传到 GitHub 还是 Gitee。 首次向 Gitee 推送时，还需要用 Gitee 的凭据或 SSH 密钥完成认证。

分支：
    仓库的最高权限是master，项目一般情况下都是多人协作开发，主分支上一般是不允许修改代码，最高权限
    一般情况下是由你的领导或者架构师操作，其余人不允许修改，一般情况下master只修改一次上传项目需要
    用到的框架和素材
    一个项目当中可能有多个分支，每个分支都是套独立的代码。都是从master分支上继承而来的

如果你到了公司需要上传代码怎么办？
    一般情况下会给你一个子分支，你就在给你的这个分支上提交你的代码即可，当你完成了所有的功能之后，确定
    自己的分支没有问题，那么就可以将自己分支上的代码合并到主分支上（合并这一步一般不用你，怕你搞砸了）

如果到了公司，项目拉取不下来，可以从下边几个方面入手？
    1.git 账号密码 输入是否正确，解决方法找凭证，删除 之后可以重新输入
    2.你的git账号权限不够，没办法进入公司项目仓库，找领导给你开放权限
    3.网速慢，项目太大，拉取可能会中断
    4.有些公司必须要用公司自己的内网地址才能拉取项目，公司的仓库放在自己的服务器上，确认你的网络
    是不是内网

仓库 如何邀请成员
    选择自己的仓库，点击右边的管理--仓库成员管理--添加成员（注意选择成员角色）就可以一起开发这个项目了

创建分支：
    第一种：远程创建分支 本地使用
    查看分支 git branch -a（一定要先拉取，本地才能看见）
    切换分支 git checkout 子分支名 （注意 切换分支前必须保证没有可以提交的代码了）
    第二种：本地直接创建了子分支 上传使用
    创建子分支 并且切换到子分支上，命令是 git checkout -b 子分支名
    将子分支提交到远程服务器上面 git push origin 子分支名 将本地子分支和远程仓库建立连接
    然后写自己的bug即可，写完之后git add .  --->   git commit   --->   git push

合并分支
    想让分支和master一致，首先要确认分支上没有任何可以提交的代码了
    git checkout master
    git merge 分支名 将这个分支合并到master上

解决冲突：用他的/用你的/整合两个人的，解决完毕之后再次提交就行
