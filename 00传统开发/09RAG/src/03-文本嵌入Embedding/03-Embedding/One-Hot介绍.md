# 一、One-Hot 是什么？

**One-Hot = 独热编码 = 只有一位是 1，其他全是 0 的向量。**

规则：

- 有多少个**不同类别**，向量就有**多少维**
- 每个类别**只在自己位置标 1**，其他全 0

## 例子

假设有 4 个词：

```
[我，爱，你，AI]
```

- 我 → **[1,0,0,0]**
- 爱 → **[0,1,0,0]**
- 你 → **[0,0,1,0]**
- AI → **[0,0,0,1]**

这就是 **One‑Hot**。

------

# 二、One-Hot 的特点

1. **极其稀疏（大部分是 0）**

2. **维度巨大**

   词典 10000 词 → 向量 10000 维

3. **完全无语义信息**

   任何两个向量的**内积都是 0**，机器不知道：

   - 苹果 和 香蕉 很像
   - 国王 和 王后 有关系

4. **无法表达相似度**

   所有词之间距离完全一样。

5. **简单、好理解、好实现**

   早期 NLP 几乎都用它。

------

# 三、One-Hot 有什么问题？

1. 维度爆炸

   

   词典 1 万词 → 1 万维向量

2. **稀疏，训练困难**

3. 完全不表达语义

   

   机器不知道词语之间的关系

4. 无法泛化

   

   没见过的词无法表示

------

# 四、One-Hot vs Embedding

你只要记住这张表，面试 / 理解都稳了：

| 特性     | One-Hot            | Embedding            |
| :------- | :----------------- | :------------------- |
| 向量     | 稀疏、大部分 0     | 稠密、连续实数       |
| 维度     | 很高（等于类别数） | 低维（50～1024）     |
| 语义     | 无任何语义         | 保留语义关系         |
| 相似度   | 所有词距离相等     | 近 = 相似，远 = 不同 |
| 泛化能力 | 差                 | 强                   |
| 用途     | 简单分类、基础特征 | 现代 NLP、推荐、RAG  |

**一句话总结：**

**One-Hot 只是标记类别，Embedding 才是理解语义。**

------

# 五、总结

- **One-Hot：告诉机器这是 “哪个词”**
- **Embedding：告诉机器这个词 “是什么意思”**

One-Hot 是**传统方法**，Embedding 是**现代 AI 的核心基础**。
