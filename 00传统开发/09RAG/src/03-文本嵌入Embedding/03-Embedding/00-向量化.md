 # One‑Hot、Word2Vec、FastText介绍
    都是"把词变成向量"的方法，目标是让计算机能处理文字。
    区别在于：越往后，向量越好用、越能表达语义、越能处理没见过的词

## 1. One‑Hot 编码

机器看不懂文字，得转数字。One‑Hot 把每个词变成只有一个 1 其余全 0 的向量。

- ✅简单
- ❌ 维度爆炸：词表有 10 万词，每个词就是 10 万维向量，99.99% 是 0，极其稀疏。
- ❌ 表达不出语义：苹果、香蕉、汽车互相距离一样，机器分不清苹果和香蕉更像。

> 所以诞生了 Embedding：把文字变成低维稠密向量，相当于语义空间里的坐标，意思相近的词，向量距离就近。RAG 检索全靠 Embedding，向量差了召回就错，最终答案也错。



## 2. Word2Vec（2013 Google）

> 核心：看一个词周围经常出现什么词，就能知道它是什么意思
>
> 两种训练模式：

1. CBOW：拿周围词猜中间词，多个上下文预测一个词，速度快，小数据集好用
2. Skip‑Gram：拿中间词猜周围词，低频词效果更好，工业常用
- 负采样 Negative Sampling：不再对全部词表做 softmax（Softmax 是一个"把一堆任意数字变成概率"的函数——输出每个数都在 0~1 之间，且加起来正好等于 1。），而是随机抽几个词当"负例"（假上下文），让模型学会把真实上下文和随机噪声区分开，大幅提速。

优点：

- 产出静态词向量，低维稠密，还能做语义计算（国王‑男人 + 女人≈王后）。

缺点（痛点）：

1. 静态向量：一词只有一个向量，分不清多义词，“苹果”永远是同一个向量， 分不清水果还是手机。
2. OOV 未登录词：训练没见过的新词直接没有向量，处理不了。
3. 遇到错别字完全不认识；出新词要整套重训，成本高。

## 3. FastText（2016 Facebook，Word2Vec 作者做的）

> 核心思想：一个词不只是完整单词，还由更小的字符片段（子词 Subword）组成
>
> 用字符N‑Gram：给词加边界符`<词>`，拆成多个连续字符片段（子词）。
>
> 词向量 = 该词的整词向量 + 所有字符 N‑gram 子词向量之和（实际实现常取平均）。整词本身也算一个"子词"

### 为什么能解决 Word2Vec 的痛点

1. 处理 OOV 新词：就算完整词训练没见过，只要组成它的字符子词训练过，拼拼凑凑就能生成向量。例如没见过 “退款中”，但见过 “退款”“款中” 的子片段，照样出向量。
2. 容错错别字：错字会有大量重合子词，还能匹配上正确词。
3. 中文新词友好，新词可由已训练的子词组合生成向量，不必加入词表全量重训。。

> 局限：训练会比 Word2Vec 稍慢；还是词级别静态表示。

### Word2Vec vs FastText 简单对比

| 能力       | Word2Vec | FastText |
| :--------- | :------- | :------- |
| 学语义     | 可以     | 可以     |
| OOV 新词   | 不行     | 可以     |
| 错别字容错 | 不行     | 可以     |
| 中文新词   | 弱       | 强       |
| 速度       | 快       | 稍慢     |

## 4. 发展脉络 & 和现代模型关系

```
【词级静态】      One‑Hot → Word2Vec → FastText
【上下文/句级】   ELMo → BERT → SentenceBERT/BGE/GTE/Qwen‑Embedding
【应用】          → RAG
```

1. FastText 最大遗产：子词 Subword 思想。BERT 用 WordPiece、GPT 用 BPE，都是子词思路，只是换成 Transformer 架构。
2. Word2Vec/FastText 做词级别向量，现代 Embedding 做句子/文档级别向量，上下文感知，可以区分多义词。
3. FastText 不算过时：子词思想一直沿用；知识库、检索场景对付新词、错别字依然好用。

## 5. 企业场景举例

客服 / 电商知识库：有 “退款流程”，用户输入 “退款中怎么办”。

- Word2Vec：“退款中” 没见过，直接无向量，召回失败。
- FastText：拆出子词，识别出和 “退款” 相关，成功召回知识库内容。

## 高频面试简答（大白话版）

1. Word2Vec 缺点：静态向量，分不清多义词；未登录词 OOV 无法处理，新词错别字搞不定。
2. FastText 解决啥：主要解决 Word2Vec 的 OOV 未登录词、新词、错别字问题。
3. FastText 核心：子词 Subword，把词拆成字符 N‑gram 子片段，子词向量求和得到词向量。
4. 为啥能处理新词：新词没见过，但构成它的子词训练过，组合子词得到新词向量。
5. FastText 和 BERT 联系：都用子词思想；BERT 额外用 Transformer，是上下文动态向量。
