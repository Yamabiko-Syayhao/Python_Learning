# 一、数据

### 1、什么是数据？

##### 数据 = 人为创造、用来描述一切东西：

- 文字：你好、白癜风
- 数字：18、3072、1024
- 图片颜色、声音高低、视频画面
- 你代码里的`[0.12,0.35,-0.22]`向量，全都是**数据**

简单记：**凡是存在电脑里、能被记录、能被运算的东西，全叫数据。**

------

### 2、核心问题：计算机只认识 0 和 1，它怎么知道存的是什么？

#### 第1步：所有内容，底层全是 01

不管你打字、存图片、存视频、存文字：

电脑硬盘 / 内存里，**归根结底只有两种状态：通电 = 1，不通电 = 0**

比如：

汉字「中」、字母 A、一张照片、一句话向量 → 底层全是长长一串：

```
01001101 10101100 00110101 ……
```

#### 第2步：靠「编码规则」翻译 01

电脑自己**看不懂意思**，它只认：

> 这串 01 按哪一套规则翻译

#### 举 3 个你能秒懂的例子

#### ① 英文：ASCII 规则

规定：`01000001` → 就代表字母 **A**

电脑按 ASCII 一读：哦，这是 A

#### ② 中文：UTF-8 规则

规定一串固定 01 组合 = 某个汉字

比如：某段 01 二进制 → 按 UTF-8 翻译 → 汉字「我」

#### ③ 图片

一串 01 → 按图片编码规则 → 拆成红 / 绿 / 蓝颜色点 → 拼成画面

#### 第3步：文字向量化

普通文字：

先用 UTF-8 存 → 还是文字

AI 看不懂汉字，又升级一套规则：

**把文字再翻译成「向量数字」**

- “白癜风怎么治”
- 转成：`[0.21, -0.33, 0.76……]`
- 这串数字 = AI 能看懂的高级「01 翻译版」

------

### 3、一句话终极总结

1. **数据**：所有记录下来的信息（字、数、图、音、向量）

2. 电脑底层**永远只有 0 和 1**

3. 靠编码规则（ASCII/UTF-8 / 图片格式 / 向量模型）

   把 01 翻译成：文字、图片、声音、语义

4. 大模型里的**向量**，就是给 AI 专门定制的、能懂语义的高级编码



### 4、中文数据编码相关知识整理表

| 分类                      | 核心内容                 | 具体说明                                                     |
| :------------------------ | :----------------------- | :----------------------------------------------------------- |
| 1. ASCII 扩展             | 早期字符编码方案         | 1. 适用场景：早期计算机系统，主要用于表示英文字符<br>2. 字符容量：仅能表示 128 个字符<br/>3. 扩展形式：基于 ASCII 扩展至 256 个或更多字符，代表方案有中国大陆 GB2312、台湾 Big5、日本 EUC-JP 等4. 局限性：仅支持单一语言，多语言混合使用时会出现编码冲突问题 |
| 2. Unicode 和 UTF-8       | 跨语言统一编码体系       | 1. Unicode：包含全球所有字符的编码系统，为每个字符映射唯一数值<br/>2. UTF-8：Unicode 的实现方式之一，采用可变长度编码（1-4 个字节表示一个字符），解决了多语言混合使用的编码问题 |
| 3. One-hot 编码（词汇表） | 机器学习文本数值转换方式 | 转换规则：每个汉字表示为仅有一个元素为 <br/>1、其余为 0 的向量，向量长度等于汉字总数量，1 的位置对应汉字索引<br/>2. 优点：简单直观，易于理解和实现<br/>3. 局限性：汉字数量庞大时，会占用大量内存资源 |
